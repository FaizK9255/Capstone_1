# Capstone 1: Florida Sales Territory Analysis

## Project Overview
This project focuses on analyzing sales performance for EmporiUm, a fictional student bookstore chain that also sells technology products, art supplies, and other merchandise. Using SQL and Excel, I will analyze the Florida (FL) sales territory to identify revenue trends, evaluate sales performance, and develop data-driven recommendations for the upcoming quarter.

## Tools and Technologies
I will use MySQL to query, filter, join, and analyze sales data. Microsoft Excel will be used to create PivotCharts and visualize sales trends. GitHub will be used to manage project files, track progress, and document the analysis.

## Analysis Objectives
The analysis will calculate total revenue and identify the reporting period, examine monthly and yearly revenue trends, and compare Florida's revenue with that of its overall region. I will also evaluate transaction counts and average transaction amounts by product category, identify top-performing stores within Florida, and develop recommendations for improving sales performance in the next quarter.

## Project Deliverables
The repository will contain SQL scripts used to perform the sales analysis, an Excel workbook featuring PivotChart visualizations, and documentation of the findings and recommendations. A recorded presentation will demonstrate the analytical process, key results, and final recommendations.
